POLÍTICA DE PRIVACIDADE — MEU CONTROLE
Última atualização: maio de 2026

1. Sobre o aplicativo
O Meu Controle é um aplicativo de controle financeiro pessoal, desenvolvido e utilizado exclusivamente pelo seu criador. O app não está disponível ao público geral e não realiza coleta de dados de terceiros.
2. Responsável
Célio Josino de Macena, pessoa física, é o único responsável pelo desenvolvimento, manutenção e uso deste aplicativo.
3. Dados armazenados
O aplicativo armazena exclusivamente dados financeiros pessoais do próprio usuário, incluindo: transações bancárias, faturas de cartão de crédito, lançamentos de despesas e receitas mensais. Esses dados são obtidos via integração com instituições financeiras através da plataforma Pluggy e por importação manual de documentos PDF.
Nenhum dado é coletado de terceiros. Nenhum dado é compartilhado, vendido ou transferido a qualquer pessoa ou organização.
4. Armazenamento
Os dados são armazenados em servidor próprio hospedado na plataforma Vercel e em banco de dados MongoDB Atlas, ambos protegidos por credenciais de acesso privadas.
5. Serviços de terceiros
O aplicativo utiliza os seguintes serviços externos para seu funcionamento:

Pluggy — agregador de dados financeiros via Open Finance
Anthropic — processamento de documentos via inteligência artificial
Vercel — hospedagem do servidor backend
MongoDB Atlas — armazenamento de dados
GitHub — repositório de código-fonte

Cada um desses serviços possui sua própria política de privacidade e termos de uso.
6. Segurança
O acesso ao aplicativo e ao backend é restrito ao próprio desenvolvedor. Não há cadastro, login público ou qualquer forma de acesso por terceiros.
7. Direitos
Por ser um aplicativo de uso estritamente pessoal, o único titular dos dados é o próprio desenvolvedor, que detém controle total sobre as informações armazenadas, podendo alterá-las ou excluí-las a qualquer momento.
8. Contato
Para dúvidas sobre esta política, entre em contato pelo e-mail cadastrado na conta de desenvolvedor do Google Play.
